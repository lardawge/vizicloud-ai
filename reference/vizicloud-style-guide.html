01 — Design Principle

Engineered, not decorated.

The idea

ViziCloud sells engineering discipline, not marketing polish. Every visual choice should read like it came from a drafting table, not a template: annotated diagrams, dimension lines, precise grids, technical labels. The design should look like proof of the same rigor the copy claims — never like decoration sitting on top of it.

How to apply it

When in doubt, ask: would this appear on an engineering drawing or a systems audit? Grid backgrounds, dashed reference lines, monospace annotations, and stamped approvals all pass that test. Gradients, soft shadows, rounded bubbly shapes, and stock-photo hero imagery do not.

06 — Signature Motifs

The visual vocabulary that makes this ours.

Before / After Schematics
Tangled dashed red lines redrawn as clean orthogonal blue routing. Use whenever showing a workflow transformation.
Title Block Labels
Every diagram or card carries a small mono-caps label, top-left, like a drawing's title block. Grounds the page in "documentation," not decoration.
Rotated Stamp
A single tilted copper stamp per page for the one claim that needs to feel "certified." Never decorative, never repeated.
07 — Voice & Tone

Direct. Specific. No hype.

The visual system only works if the copy earns it — technical confidence, not sales language.

Say

"We build custom automation to bridge your tools."

Concrete, specific, describes the actual mechanism.

Not

"Unlock the power of AI for your agency."

Vague, hypey, could belong to any competitor.

Structure

Problem, named plainly → Fix, named plainly.

Never bury the pain point in a euphemism. Recruiters should recognize their own desk immediately.

08 — Do / Don't

Keep new pages on-system.

Do

  • Use the 32px grid as a literal background texture in hero moments
  • Keep every diagram labeled like a real technical drawing
  • Let copper carry the only warm color on any given page
  • Use hairline borders and offset shadows instead of soft blur shadows
  • Write mono-caps labels in the same voice as an audit file

Don't

  • Add gradients, glassmorphism, or rounded bubble buttons
  • Introduce a second display typeface
  • Use stock photography of people in the hero
  • Let the stamp or dimension-line motif appear more than once per page
  • Mix warm accent colors — copper is the only one
